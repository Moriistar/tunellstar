## 🚀 **معرفی StarTunnel**  
**تونل استار (StarTunnel)** یک راه‌حل **سریع، سبک و هوشمند** برای ایجاد ارتباط امن و پایدار بین سرورهاست! این ابزار با ترکیب فناوری **VXLAN** و **HAProxy**، یک تونل پرسرعت با مدیریت خودکار ترافیک ارائه می‌دهد.  

✨ **چرا StarTunnel؟**  
- **راه‌اندازی آسان** — بدون نیاز به تنظیمات پیچیده!  
- **پایداری بالا** — حتی در شرایط محدودیت شبکه.  
- **بهینه‌سازی شده** — کمترین مصرف منابع، بیشترین کارایی!  

---

## 🔥 **ویژگی‌های کلیدی**  

### **🛠️ فناوری‌های به‌کاررفته**  
| فناوری | توضیحات |  
|--------|---------|  
| **VXLAN** | ایجاد تونل‌های مجازی با پوشش گسترده و تاخیر کم |  
| **HAProxy** | مدیریت هوشمند ترافیک و تعادل بار (Load Balancing) |  
| **BBR** | بهینه‌سازی انتقال داده با الگوریتم Google BBR |  

### **📡 امکانات اصلی**  
- **🚀 تونل‌سازی فوق‌سریع** با پروتکل VXLAN  
- **🌐 پشتیبانی از IPv4 محلی** (حتی در شرایط فیلتر IPv6)  
- **⚡️ مدیریت خودکار ترافیک** با HAProxy  
- **🔒 امنیت بالا** با فیلترهای پیشرفته iptables  
- **📊 نمایش لحظه‌ای وضعیت سرور** (کشور، ISP و IP)


### **📌 گزینه‌های منو**  
| گزینه | عملکرد |  
|-------|---------|  
| **1️⃣ نصب تونل جدید** | ایجاد تونل بین ایران و خارج |  
| **2️⃣ حذف تونل‌ها** | پاکسازی کامل تونل‌های موجود |  
| **3️⃣ نصب BBR** | بهینه‌سازی شبکه برای سرعت بیشتر |  
| **4️⃣ مدیریت HAProxy** | تنظیمات پیشرفته فورواردینگ پورت |  

---

## ⚡ **HAProxy چیست؟**  
**🔹 HAProxy** یک **لود بالانسر** و **پروکسی** رایگان و اپن‌سورس است که برای مدیریت ترافیک TCP/HTTP طراحی شده. این ابزار با توزیع هوشمند درخواست‌ها بین چندین سرور، باعث **کاهش تأخیر** و **افزایش پایداری** می‌شود.  

✅ **مزایای استفاده از HAProxy در StarTunnel:**  
- **تعادل بار خودکار** بین سرورها  
- **فورواردینگ چندپورتی** بدون نیاز به کدنویسی  
- **پشتیبانی از فیلترهای امنیتی** پیشرفته
